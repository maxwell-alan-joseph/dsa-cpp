## Layout

```
01-loops-patterns/
  001-print-1-to-n.cpp
  002-right-triangle-pattern.cpp
03-arrays/
  001-two-sum.cpp
...
TEMPLATE.cpp
```

Files are named `NNN-problem-name.cpp`. Every file starts with the header from `TEMPLATE.cpp`: the problem link, my approach in one or two lines, and time and space complexity.

## Running a solution

```bash
g++ -std=c++17 -O2 -Wall 03-arrays/001-two-sum.cpp -o run && ./run
```
